## Build / delivery limits

The lazy intake chunk is approximately 32.6kB JS / 10.7kB gzip plus 12.5kB CSS / 3.1kB gzip. Existing React/router/motion chunks remain separate. No application dependency was added.

The host uses Node **22.9.0**. Vite 7 warns that supported versions are 20.19+ or 22.12+; the build nevertheless completes. Upgrade the local runtime before production deployment.

No Sanity project/Studio, production submission endpoint, real team destinations, analytics vendor or deployment was configured. No real inquiry was sent. Qualification drafts are local, versioned and expire after seven days; contact and consent are excluded.
